# 🤖 AI Face Attendance System

An AI-based Face Attendance System built using Python, OpenCV, Face Recognition, Tkinter, and Excel.

## 📌 Project Overview

The AI Face Attendance System automatically identifies registered students using facial recognition and records their attendance.

The system provides:

- Face recognition
- Automatic attendance marking
- Duplicate attendance prevention
- Student registration
- Student management
- Student search
- Face encoding
- Attendance dashboard
- Present/Absent statistics
- Attendance percentage
- Excel attendance records
- Attendance backup and cleaning

## 🛠️ Technologies Used

- Python
- Tkinter
- OpenCV
- Face Recognition
- NumPy
- Pandas
- OpenPyXL
- Pillow
- Matplotlib
- JSON
- Excel
